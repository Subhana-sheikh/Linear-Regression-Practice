# Linear Regression Practice 📈

A hands-on Machine Learning practice repository focused on understanding and implementing **Linear Regression** using Python.

## 📌 Overview
This repository contains my practice notebook covering the fundamentals of Linear Regression, data preprocessing, model training, and evaluation. I built and practiced this implementation by following **Krish Naik's** tutorial videos as a learning reference.

## 🛠️ Technologies & Libraries Used
* **Python 3**
* **Google Colab**
* **NumPy** – Numerical computations
* **Pandas** – Data loading and manipulation
* **Matplotlib / Seaborn** – Data visualization and regression line plotting
* **Scikit-Learn** – Train-test split, model building, and performance evaluation

## 🚀 Key Concepts Covered
* Exploratory Data Analysis (EDA) & Data Visualization
* Splitting dataset into Training and Testing sets
* Training a Simple/Multiple Linear Regression model
* Evaluating model performance using metrics ($R^2$ Score, MSE, MAE)
* Visualizing the best-fit line against actual data points
